# Pairify

**Quick pair up for your next activity.**

Pairify is an online activity-sharing and partner-matching platform designed by CCIT4078 group A2. It helps users organise activities, invite friends, discover potential partners with similar interests, and manage their schedules more easily.

Instead of messaging every friend individually to find a suitable time, users can create an activity, share its details, and let others join with one click. Pairify also supports matching users based on hobbies, skill levels, and availability.

## Run locally on Windows

1. Install [Node.js](https://nodejs.org/) if it isn't already installed.
2. Double-click `start-pairify.bat`.
3. Open [Pairify on localhost](http://127.0.0.1:8765/) in your browser.

Keep the server window open while using Pairify. Press Ctrl+C to stop it. The launcher uses Node.js built-in modules, so no npm install or VS Code extension is needed.
