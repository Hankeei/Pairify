# Exclusive Summary

As matching every friend\'s schedule is troublesome, it is difficult for
individuals to hold an activity with friends. Pairify provide a
convenient, secure, sustainable online platform for users to plan, hold
or join an activity, pair a partner or make friends in a flexible way.

The project aims to develop an online platform which is user-friendly
and compulsory, started from 17 Sep 2026 to 28 Apr 2027 which is the
one-year project with 6 members around 960 man hours, including UI
design, Server and database setting, activity and pairing system.

# Background

# Nowadays, many people lead busy lives, which increases the difficulty of finding partners with free time to join activities. Organizing activities can become time-consuming, as users must check each friend's schedule individually. 

# For example, asking a friend to do sport together would be challenging because not everyone has the same schedule. Work, study, and other commitments may also affect the schedule. As a result, users may give up doing activities together.

# Project Objective

-   Develop a working online platform where users can create, view, and
    join activities within the project period.

-   Implement user authentication and friend management so that only
    connected friends can view and join private activities.

-   Enable hosts to see a clear list of participants for each activity.

-   Achieve basic usability so that a new user can create or join an
    activity within a few clicks.

-   Complete development, testing, and documentation by the project
    deadline.

# Problem solution

Our proposed solution is Pairify, an online event-sharing platform that
allows users to make, discover, and enter activities with their friends.
Pairify is designed for users to organize social activities easily, by
providing a centralized space where event information can be shared
clearly and efficiently.

On Pairify, users can organize an event by entering the title,
description, date, time, and location of the event and share it with
friends on the platform. As a result, friends can view the event details
and click the "Join Activity" button if they would like to participate.
The host can then view the list of participants and have further
arrangements.

Apart from holding activities with friends, Pairify also provides
pairing function for users who with no partners or purely want to have
new friends. When users register, besides their basic information they
may provide their hobbies levels. Users may find a partner on Pairify
based on their hobbies, levels and requirements.

# With Pairify, this process becomes much simpler. A user can find an activity that they want to do (for example, which workout they will do) along with the date and time. Friends who see the activity can check their own availability and, if they are free, simply click the "Join Activity" button to pair up and join. This reduces the effort needed to coordinate schedules and makes it easier for friends to do activities together. At the same time, if users want to meet new friends during the activity, then use the pairing function and find users who would like to join the event, which solves if friends are not available.

# Targeted Users

Registered users: Can pair a partner with the same sport hobby or hold
activities with users in the same friend group.

Friends / participants: Can manage activities, view shared activities,
join activities, and track their participation.

# Function

Based on our purpose we aim for the pursuit of convenience, for users
matching their friends in efficiency way. A clean, intuitive UI enables
users to access our functions in just a couple clicks.

User Management: Allowing users to register, log in/log out, edit
profile or manage friends list.

Activity Creation and Management: Allowing users to hold an activity by
typing title, description, date, venue, optional maximum number of
participants in the provided form. Users may edit or cancel the event
and view the list of participants anytime.

Activity Voting: Allowing users to view the existing activity details
and vote whether they will participate by clicking the provided \"Join
Activity\" button.

Pairing: Allowing users to find a partner based on their habits, stages
and schedule.

Map Integration: Allowing users to view the location of the event,
locate their current position, and provide ways to the venue.

Calendar: Allowing users to view the calendar, planning and matching
their schedule, to avoid a conflict between event and event or their own
timetables.

Notification: Allowing users to receive an in-platform notice when an
activity is held/updated/cancelled.

Non-function\
Usability: The interface should be intrusive and simple. A new user
should be able to access the function with a few clicks. Information
should be easy to understand.

Maintainability: The codebase should be structured and documented well.
Easy for future adjustment and development.

Reliability: The system should correctly save the display the activities
and other information without unjustified data loss.

Security: The *system uses* the two-factor authentication (2FA) function
to confirm the validation and the all user information should be
encrypted to protect the confidentiality.
